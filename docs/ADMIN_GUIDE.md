# Guide administrateur

## Modifier le menu public

1. Lancer l’éditeur: `python editor.py`.
2. Mettre à jour les réglages d’entreprise, le menu courant, les zones de livraison ou les items.
3. Utiliser **Validate data** avant de sauvegarder.
4. Prévisualiser le site avec `python main.py`.

## Points à confirmer avant production

- Minimum exact de commande: 30 $ ou 35 $.
- Seuil de livraison gratuite.
- Jours de livraison fixes ou variables.
- Paiement complet en ligne, dépôt ou paiement à la livraison.
- Modalités du rabais de référence de 10 $.
